# 应聘通

> 一款基于 WinForms 的招聘信息管理工具，助力求职者高效追踪投递进度。

---

## ✨ 项目简介

**应聘通**是一款独立发布的桌面端招聘管理程序，专为求职者设计。它可以帮你系统化地管理投递过的公司、追踪面试阶段、记录反馈信息，让求职之路更有条理。

---

## 🛠️ 技术栈

本项目基于以下开源 NuGet 包开发，在此致以诚挚感谢：

- **WinformLib** —— UI 控件与窗体组件库
- **FreeSql** —— 轻量级 ORM 数据库框架
- **SQLite** —— 本地嵌入式数据库

> 🙏 感谢所有开源贡献者的辛勤付出！

## 📋 功能特性

### 1. 🏢 公司新增功能
- 快速录入投递公司信息
- 支持公司名称、岗位、薪资、地点等多字段管理

### 2. 📍 公司状态管理
- **地图查看**：直观展示公司地理位置分布
- **备注信息**：随时记录面试感受、公司评价等备忘

### 3. 🔍 智能查询功能
- **近 7 天有反馈**：一键筛选近期活跃投递
- **显示非拒绝**：自动过滤已拒岗位，聚焦有效机会
- **按阶段筛选**：支持多阶段过滤
- **按公司类型筛选**：按企业性质分类查看

### 4. 📣 招聘渠道维护
- 自定义管理招聘渠道（BOSS、智联、猎聘等）
- 支持渠道的新增、编辑与删除

### 5. 🗑️ 信息一键清空
- 支持批量清空所有公司数据
- ⚠️ **温馨提示**：清空后数据将永久删除且不可恢复，请谨慎操作！

## 🚀 使用说明

1. 下载并解压发布包
2. 双击运行 `应聘通.exe`
3. 首次启动会自动创建本地 SQLite 数据库
4. 开始录入你的投递信息吧！
